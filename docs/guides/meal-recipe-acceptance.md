## 3. 发布阻断项

出现下列任一情况，不应上传审核：

- 任何构建产物仍包含 `localhost:8000`；
- 游客登录或微信登录失败；
- AppSecret、数据库密码或 JWT 密钥进入 Git/前端产物；
- CloudBase 环境 ID、服务名或端口与约定不一致；
- 关键菜谱没有按逐人份表达，或能量被展示成医疗级精确值；
- 确认整套餐出现重复/冲突记录；
- 320 px 宽度出现横向滚动或关键按钮不可点击；
- 云托管冷启动后迁移/种子初始化失败。

能量值是食材和标准份量的估算，用于日常参考，不应包装成营养诊断。产品可以聪明，不能装医生。
